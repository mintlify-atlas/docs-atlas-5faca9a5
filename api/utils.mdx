The utils module provides a collection of helpful utility functions for common tasks when building Discord bots, including async iteration, environment variable validation, module discovery, and client lifecycle management.

## Import

```typescript
import {
  collect,
  entries,
  useEnv,
  glob,
  lazy,
  login
} from 'mygourd/utils';
```

## Function categories

### Async utilities

- **collect** - Simplifies working with async iterators by collecting all values into an array
- **lazy** - Creates memoized async value fetchers for expensive operations

### Type safety

- **entries** - Enhanced Object.entries with better TypeScript inference and handling of partial objects
- **useEnv** - Runtime validation of environment variables using Arktype schemas

### Module discovery

- **glob** - Dynamically import TypeScript/JavaScript modules using glob patterns, used internally by router functions

### Client lifecycle

- **login** - Handles Discord client login, SIGINT/SIGTERM signals, and graceful shutdown with custom cleanup handlers

## Common use cases

The utils module is designed to support common patterns in Discord bot development:

- Validating required environment variables on startup
- Dynamically loading command and event modules
- Handling graceful shutdown when the bot is stopped
- Working with async data sources and iterators
