title: Interactions

---

The interactions module provides a powerful routing system for Discord interactions, including slash commands and context menu commands. It handles both registration with Discord's API and runtime routing of interaction events.

## Import

```typescript
import {
  createInteractionRouter,
  createInteractionRouterCommand,
  createInteractionRouterMenu,
  isInteractionModule,
  registerInteractionRouters,
  globInteractionRouters
} from 'mygourd/interactions';
```

## Types

The module exports the following types:

- `InteractionModule` - A branded interaction module
- `InteractionModuleShape` - Mapping of interaction types to definitions
- `InteractionDefinition<T>` - Type-safe interaction definition with handler
- `InteractionType` - Union of supported interaction types (`commands` | `menus`)
- `InteractionEventMapper` - Maps interaction types to Discord.js event types
- `InteractionShapeMapper` - Maps interaction types to builder types
- `SerializableShape` - Interface for serializable command definitions

## Utilities

- `isInteractionModule(v: unknown): v is InteractionModule` - Type guard to check if a value is a valid interaction module. Used internally by the glob functions for validation.

## How it works

Interaction modules support two types of interactions:

- **Commands** - Slash commands using `SlashCommandBuilder`
- **Menus** - Context menu commands using `ContextMenuCommandBuilder`

The module automatically handles:
- Registering commands with Discord's API
- Routing incoming interactions to the correct handler
- Type-safe event handling based on interaction type
