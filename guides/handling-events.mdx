---
title: Handling events
description: Learn how to handle Discord events with mygourd's event router system
---

mygourd provides a type-safe event handling system that automatically registers your event handlers with the Discord.js client.

## Creating event handlers

<Steps>
  <Step title="Import the event router function">
    Import `createEventRouter` from `mygourd/events`:

    ```ts
    import { createEventRouter } from 'mygourd/events';
    ```
  </Step>

  <Step title="Define your event handlers">
    Create an event router with handlers for the Discord events you want to listen to:

    ```ts
    import consola from 'consola';
    import { createEventRouter } from 'mygourd/events';

    export default createEventRouter({
      clientReady: () => {
        consola.info(`The bot is ready!`);
      },
    });
    ```
  </Step>

  <Step title="Place the file in your events directory">
    Save your event file in a location that matches your glob pattern (e.g., `events/login.ts`).

    The events will be automatically discovered and registered when you use `globAllRouters` or `globEventRouters`.
  </Step>
</Steps>

## Common event handlers

Here are some commonly used Discord events:

### Client ready

Triggered when the bot successfully connects to Discord:

```ts
import consola from 'consola';
import { createEventRouter } from 'mygourd/events';

export const readyEvents = createEventRouter({
  clientReady: (client) => {
    consola.info(`Logged in as ${client.user.tag}`);
    consola.info(`Serving ${client.guilds.cache.size} guilds`);
  },
});
```

### Message events

Handle message creation and updates:

```ts
import { createEventRouter } from 'mygourd/events';

export const messageEvents = createEventRouter({
  messageCreate: async (message) => {
    if (message.author.bot) return;
    
    if (message.content.startsWith(`!hello`)) {
      await message.reply(`Hello, ${message.author}!`);
    }
  },
  messageUpdate: (oldMessage, newMessage) => {
    console.log(`Message edited: ${oldMessage.content} -> ${newMessage.content}`);
  },
});
```

### Guild events

Track when your bot joins or leaves guilds:

```ts
import consola from 'consola';
import { createEventRouter } from 'mygourd/events';

export const guildEvents = createEventRouter({
  guildCreate: (guild) => {
    consola.success(`Joined guild: ${guild.name} (${guild.id})`);
  },
  guildDelete: (guild) => {
    consola.warn(`Left guild: ${guild.name} (${guild.id})`);
  },
});
```

### Member events

Handle member joins, leaves, and updates:

```ts
import { createEventRouter } from 'mygourd/events';

export const memberEvents = createEventRouter({
  guildMemberAdd: async (member) => {
    const channel = member.guild.systemChannel;
    if (channel) {
      await channel.send(`Welcome ${member.user} to ${member.guild.name}!`);
    }
  },
  guildMemberRemove: async (member) => {
    console.log(`${member.user.tag} left the server`);
  },
});
```

## Multiple event routers

You can create multiple event routers in the same file, which is useful for organizing related functionality:

```ts
import consola from 'consola';
import { createEventRouter } from 'mygourd/events';

export const loginEvents = createEventRouter({
  clientReady: () => {
    consola.info(`The bot is ready!`);
  },
});

export const loginEvents2 = createEventRouter({
  clientReady: () => {
    consola.info(`The bot is ready, but in a different router!`);
  },
});
```

<Note>
  Both event handlers will be executed when the event fires. This allows you to organize your code into logical modules while still handling the same events.
</Note>

## Event handler parameters

All event handlers receive the same parameters as Discord.js events. The types are automatically inferred:

```ts
import { createEventRouter } from 'mygourd/events';

export const typedEvents = createEventRouter({
  // client is typed as Client<true>
  clientReady: (client) => {
    console.log(client.user.tag);
  },
  // message is typed as Message
  messageCreate: (message) => {
    console.log(message.content);
  },
  // oldPresence and newPresence are typed as Presence
  presenceUpdate: (oldPresence, newPresence) => {
    console.log(`${newPresence.user?.tag} status changed`);
  },
});
```

## Registering event handlers

Event handlers are automatically discovered and registered when you use the glob functions:

```ts
import { Client } from 'discord.js';
import { globAllRouters } from 'mygourd/routers';

const client = new Client({
  intents: [`Guilds`, `MessageContent`, `GuildMessages`],
});

await globAllRouters(
  client,
  [`events/**/*.ts`, `interactions/**/*.ts`],
  import.meta.dir,
);
```

<Warning>
  Make sure your bot has the necessary intents enabled for the events you want to handle. For example, `GuildMessages` and `MessageContent` intents are required for message events.
</Warning>

## Best practices

<Accordion title="Organize events by category">
  Group related events together in separate files:
  ```
  events/
  ├── ready.ts         # Bot startup events
  ├── messages.ts      # Message-related events
  ├── members.ts       # Member join/leave events
  └── moderation.ts    # Moderation-related events
  ```
</Accordion>

<Accordion title="Filter bot messages early">
  For message events, filter out bot messages at the start to avoid self-triggering:
  ```ts
  messageCreate: async (message) => {
    if (message.author.bot) return;
    // Your logic here
  }
  ```
</Accordion>

<Accordion title="Handle errors in event handlers">
  Always wrap event handler logic in try-catch blocks to prevent crashes:
  ```ts
  import consola from 'consola';
  import { createEventRouter } from 'mygourd/events';

  export const safeEvents = createEventRouter({
    messageCreate: async (message) => {
      try {
        // Your event logic
      } catch (error) {
        consola.error(`Error handling message:`, error);
      }
    },
  });
  ```
</Accordion>

<Accordion title="Use appropriate intents">
  Only request the intents you need to minimize data transfer and comply with Discord's requirements:
  ```ts
  const client = new Client({
    intents: [
      `Guilds`,              // Required for basic bot functionality
      `GuildMessages`,       // Required for message events
      `MessageContent`,      // Required to read message content (privileged)
      `GuildMembers`,        // Required for member events (privileged)
    ],
  });
  ```
</Accordion>
